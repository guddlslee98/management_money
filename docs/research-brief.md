# 가계부 앱 리서치 정리 (2026-09-05 기준)

> 이 문서는 앱을 만들기 전에 수행한 조사 결과를 결정 사항 중심으로 정리한 것이다.
> 6개 주제(기존 가계부 앱, 국내 자동연동 가능성, 기술 스택, 도메인 모델, 국내 카테고리 체계, 개발 도구)를
> 각각 별도 조사 에이전트가 1차 출처(공식 문서·소스코드·npm·공식 도움말)를 인용해 정리했다.
> **주의:** 계획했던 교차 검증(반박) 단계는 세션 사용량 한도로 실행되지 못했다. 따라서 아래 수치·사실은
> 조사 에이전트가 출처와 함께 보고한 내용이며, 직접 재확인한 항목(npm 버전, Context7 도구명, 스모크 테스트)만 검증 완료로 표시했다.

## 5. 도메인 모델과 계산 규칙 (조사 → 채택)

- **거래 종류를 명시** (`expense | income | transfer`), 금액은 정수 원, 항상 0 이상. 환불은 `isRefund`.
- **이체 제외:** 수입·지출·카테고리 비율 어디에도 이체를 넣지 않는다. 카드 구매는 이용일에 지출, 카드대금 납부는 은행→카드 이체.
- **비율 2층:** 대분류 pct = 대분류 순지출 / 총 순지출, 소분류 pct = 소분류 / 대분류. 분모 ≤ 0이면 0. 환불 초과로 음수인 카테고리는 금액은 음수로 유지하고 pct는 0.
- **미분류:** DB 행이 아닌 가상 버킷으로 리포트에서 합성.
- **반복 거래:** 발생일(월 말일 보정)이 지나면 앱을 열 때 생성, `recurringRuleId+month`로 멱등. 미래 거래는 미리 만들지 않는다.
- **예산:** 대분류 × 월. `'*'`는 기본(매월) 예산, 특정 월 예산이 우선. 예산 0원이면 사용률 0.
- 조사에서 제안됐지만 v1에서 제외한 것: 분할 거래, 급여일 기준 월(`monthStartDay`), 통계 제외 플래그(`exclude_from_stats`), 고정지출 플래그, 이체 자동 매칭(4일 창), 달력 뷰 → 6절 향후 과제.

## 6. 기본 카테고리와 자동 분류

- 통계청 가계동향조사 12대 항목(COICOP-K)과 국내 앱 관행(뱅크샐러드 28개/119개, 토스·편한가계부 등)을 참고해 **지출 대분류 12~14개 + 소분류, 수입 대분류 6~7개**를 `src/data/default-categories.ts`에 정의했다. 색상은 라이트(#fafafa)·다크(#111) 배경 모두에서 대비 4:1 이상.
- 자동 분류 규칙 120개 이상: 가맹점 키워드(스타벅스, GS25, 배달의민족, 쿠팡, SKT, 넷플릭스, 관리비, 급여 …)를 우선순위(브랜드 100 > 일반어 50)와 **최장 일치** 규칙으로 평가한다. 사용자가 카테고리를 바꾸면 거래처 기반 사용자 규칙(우선순위 1000)을 학습한다.

## 7. 개발 도구

- **Context7**: `.mcp.json`의 `@upstash/context7-mcp`(4.0.5, 도구 `resolve-library-id`·`query-docs`, API 키 선택). 최신 메이저(Vite 8, react-router 8, Recharts 3, Vitest 5, Tailwind 4)가 학습 데이터보다 새롭기 때문에 라이브러리 API는 전부 Context7 문서로 확인하며 작성했다.
- **agent-browser**: 0.36.0, `.mcp.json`의 MCP 서버 + `scripts/e2e-smoke.sh`(`npm run e2e:smoke`). 실제 Chromium에서 홈 렌더링, 탭 이동, `window.__mm` 샘플 시딩, 페이지 JS 오류 없음, 스크린샷까지 7개 검사를 수행한다. 이 샌드박스의 헤드리스 브라우저는 localhost만 접근 가능하다.
- 자세한 사용법: `docs/dev-tooling.md`.

## 8. 열린 질문과 향후 과제

1. 급여일 기준 월(예: 25일 시작)을 지원할지 — 조사한 앱들은 모두 달력월이지만 국내 사용자 요구가 있음.
2. 카드 할부를 구매 시점 전액으로 볼지, 청구 월별로 나눌지(소비 분석 vs 현금흐름).
3. 환불이 다른 달에 발생했을 때 원 거래 달을 소급할지(현재는 환불 발생 달에 차감).
4. 뱅크샐러드·편한가계부 카테고리명 → 앱 카테고리 매핑 표는 실제 내보내기 파일 샘플로 확정 필요.
5. Android 알림 파싱 컴패니언 앱, Gmail 첨부 자동 수집 파이프라인은 자동화가 꼭 필요할 때의 확장 옵션.
6. 조사 결과의 교차 검증(반박 단계) 재실행.
